## 🚀 Featured Projects

### QuMail — Quantum-Secure Email Client
> *A proprietary PQC implementation for civilian communications, aligned with ISRO standards and national security deadlines.*

QuMail adds a transparent layer of **post-quantum cryptography** to Gmail and Yahoo — with no changes needed from recipients. Built in alignment with **ISRO Problem Statement PS 25179** and India's CII PQC deadline of December 31, 2028.

- 🔐 Three-tier encryption: **Quantum OTP → QKD-seeded AES-256-GCM → ML-KEM FIPS 203**
- 🛰️ ETSI GS QKD 014 Virtual KME — drop-in ready for live QKD infrastructure
- ☁️ Cloud Run portal for non-QuMail recipients with Firestore session isolation
- 🏆 **2nd Runner Up — HackToon 1.0, AIKTC**

### Quantum-AI Hybrid Defense System — Four-Layer Cybersecurity Architecture
> *Hardware entropy → BB84 QKD simulation → Neuro-Symbolic AI → Quantum-signed transactions.*

A research-grade, four-layer defense system integrating a physical entropy engine, quantum cryptography simulation, and adaptive AI to defeat both classical and post-quantum threats.

- ⚡ **Hardware Root of Trust** — ESP32 Zener diode avalanche noise TRNG with Von Neumann debiasing and CSPRNG hot-failover
- 🔬 **BB84 QKD Simulation** — Physics-accurate protocol with QBER eavesdrop detection and Decoy State Protocol for PNS attack mitigation
- 🧠 **Neuro-Symbolic AI** — Isolation Forest anomaly detection + symbolic rule engine (XSS, SQLi, Impossible Travel)
- 🏦 **Quantum Bank PoC** — HMAC-SHA256 transaction signing from quantum-derived keys; MITB attack blocked and logged
